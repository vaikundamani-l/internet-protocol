# Model boundaries

Version 3 adds calculated CUBIC curves, BBR bandwidth-delay-product and pacing arithmetic, TCP state paths and receiver/congestion-window budgets, DNSSEC decisions, CORS decisions and flow hashing. These are selected mechanisms, not full implementations of those standards.

Every model exposes its inputs, computed event trace and limitations. The Simulation tab offers the complete model selector, so related mechanisms can be compared. Some chapters share models; model count is not a count of independently implemented protocols.

The CUBIC curve omits the full congestion-control state machine and TCP-friendly region. The BBR calculator does not implement its probing, filtering or version-specific recovery. Routing models do not run real OSPF/BGP daemons. DNSSEC decisions do not verify signatures. Use the masterclass experiments with actual implementations for those behaviors.

Synthetic PCAPs are generated by the browser. Observed PCAPs in evidence/ are separate artifacts captured from owned loopback exchanges; metadata records their source and hashes. Loopback observations do not establish WAN behavior.

Reading completion is a self-report. Chapter quizzes, the 30-question examination and 12 automatically graded calculations provide distinct practice evidence. They are not invigilated qualifications. Project and investigation rubrics require the learner to supply actual results.

GitHub Pages serves static content. Progress is local to a browser and can be exported/imported. There is no account-based sync, remote lab execution or hosted production backend.
